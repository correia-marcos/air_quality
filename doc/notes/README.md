# Local research and explanation notes

Only this README is tracked; other contents are ignored and excluded from container builds.
Use `<date>-<topic>.md` for new explanatory calculations, exploratory research narratives,
or session notes that are not audits. Record source revisions and qualifications.

Historical notes inside `doc/audits/` remain at their existing paths. Directory placement
does not turn a research note into a procedure audit or confer review status.

For reviewed public material, link or propose a sanitized document in the appropriate
guide/reference location. The current public supporting-analysis guide is
[geographic-resolution sensitivity](../RESOLUTION_SENSITIVITY.md). Preserve its definitions
and empirical qualifications; new publication or manuscript changes need their own scope.
